# 实现模块（待实现）

实现按 [模块接口](../docs/interfaces.md) 和 [日志规范](../docs/logging_spec.md) 逐步加入，建议划分为：

- env：官方环境与任务适配、玩家观察、合法动作和原生指标。
- agents：统一 DeepSeek 调用、基础 Agent 与明确区分的候选方法。
- runner：逐局循环、执行反馈、停止条件和费用记录。
- trace：逐步证据与逐局汇总的保存。
- analysis：失败分类、行为统计、配对比较和图表。

目前只有职责说明，没有占位类或可运行模块。各模块的实现应先满足一条真实观察—动作链路和完整调用记账，再扩展到 500 局诊断采集。runner 不设每局 API 调用上限，采用原生终局和 2,000 步宽停止线；具体规则以研究设计为准。
