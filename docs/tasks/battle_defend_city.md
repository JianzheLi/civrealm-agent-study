# battle_defend_city：守城

## 基本信息

| 项目 | 内容 |
| --- | --- |
| task_type | `battle_defend_city` |
| difficulty | `normal` |
| 规则来源 | CivRealm 小游戏存档 `minitask_T1_task_battle_defend_city_level_normal_id_<id>.sav` 的 Lua 任务脚本；已在 songluo 本地环境抽查 normal ID 0、1、999，核验镜像 ID 为 `sha256:d4ce74d7eb7401ff2383761484f4ccb12b5cd0d9193f4cc4be3c8a0ab257f4a5`，该 ID 是核验证据而非全组强制部署方式 |
| 典型初始条件 | 我方有 1 座城市和若干守军，敌方没有城市并以陆军进攻。抽查样本的我方/敌方单位数分别为 8/8、2/3、4/4；具体兵种、位置和数量按实例变化 |
| 原生回合期限 | Lua 变量 `max_turn = 50`；`turn_begin` 在 `turn == max_turn` 时将未提前结束的任务判为成功 |

## 给 Agent 的目标与规则

使用现有单位守住己方城市直到原生期限，同时可以消灭全部进攻单位提前取胜。每次只能从当前环境提供的合法动作映射中选择一个动作；移动、战斗、驻防和城市生产均遵循 Freeciv 原生规则。

守住城市是硬约束。城市被摧毁或转移给其他玩家会立即触发失败；不能用较高分数、击杀多数敌军或文字说明代替城市归属和原生终局。

## 原生结局与评分

- `human_unit_cnt`、`ai_unit_cnt` 和 `human_city_cnt` 分别为我方单位数、敌方单位数和我方城市数。
- `mini_score = human_unit_cnt + human_city_cnt - ai_unit_cnt`，越大表示守方的单位与城市净优势越大。
- `mini_goal = human_unit_cnt + human_city_cnt`。该目标随当前我方存量变化，不是固定的初始阈值。
- `ai_unit_cnt == 0` 时提前成功；我方城市数变为 0、城市被摧毁或城市发生转移时提前失败。
- 未提前结束并到达第 50 回合时，Lua 将任务判为成功。若游戏在脚本仍未决时结束，则仅在我方仍有 1 座城市时判为成功。
- `is_mini_success` 是最终评测依据。成功消息函数会把 `mini_goal` 改写为当时的 `mini_score` 以生成文本，因此分析应优先保存终局消息前的原生 metrics，并记录字段出现变化的时点。

## 玩家可见信息与动作

统一 Agent 输入只使用玩家侧接口提供的信息：当前回合、Lua 播报的任务指标、己方可行动单位和城市，以及 `LLMWrapper` 生成的局部地图和较粗粒度周边块摘要。城市观察还包含当前生产项目。未探索区域、敌军不可见位置和存档中的全局布局不得补给模型。

相关动作包括当前合法的单位移动、战斗与驻防类动作，以及城市当前合法的生产动作；统一 wrapper 对城市只保留 `produce` 类别。动作名称、actor ID 和参数必须来自当步有序 `legal_actions`。不得用隐藏敌军坐标进行路线筛选或替 Agent 自动执行防守规则。

## 进展证据与需要记录的事件

逐步保存城市归属、城市位置摘要、当前生产、玩家可见威胁、己方守军、敌方可见单位、合法动作、实际命令和战斗反馈。每次伤亡记录损失方及前后的 `human_unit_cnt`、`ai_unit_cnt`、`human_city_cnt`、`mini_score`、`mini_goal` 和 `is_mini_success`。

以下事件分别记录：敌军接近城市、守军移动或驻防、城市生产变化、双方单位损失、敌军清零、城市被摧毁、城市转移、回合推进至 50 和原生任务终局。命令被提交或单位进入城市地块不等于已经守城成功。

## 运行与分析说明

采用 [研究设计](../llm_study_design.md) 的原生终局、2,000 步宽停止线和无每局 API 调用上限。记录要求见 [日志规范](../logging_spec.md)。50 回合是本任务有语义的原生防守期限；2,000 env steps 只防止 runner 无限运行，触及它而原生状态未决时应记为 `step_limit`，不能改写为原生失败。

分析至少报告原生成功率、城市最终归属、到达期限或提前终局的比例、双方伤亡、最终分数，以及 env steps/API 调用/token。对消灭全部敌军的提前成功和守到期限的成功分开统计。
