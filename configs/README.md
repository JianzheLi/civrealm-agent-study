# 第一轮配置与场景清单

当前先开展五个 normal 任务各 100 局、共 500 局的基础轨迹统计与失败分析，配置和实例清单随后由真实实现生成。本目录不保存凭据或游戏存档。

全组统一使用首轮开始时最新发布的 DeepSeek，2026-11-01 核对为 DeepSeek-V4.1-Flash-1017，API model=deepseek-flash。保存官方参考版本、核对日期、请求别名、实际返回模型、thinking/high、生成上限及基础提示词版本，不能各组使用不同模型后混合结果。

配置同时确定任务规则来源、代码版本、历史与记忆、纠错/重试规则、100 个实例的清单和抽样种子、可控游戏随机设置、运行顺序与输出位置。原生终局优先，宽松停止线为每局 2,000 环境动作，不设独立 API 调用次数上限（max_api_calls 的语义为 null）。

先用每任务前 5 个场景确认链路、日志和可视化字段，随后使用统一配置采集。每位成员交付自己任务类别的结果表、轨迹索引、案例和图；具体分工见根目录 README。

参数见 [研究设计](../docs/llm_study_design.md)，字段见 [日志规范](../docs/logging_spec.md)，当前统计与绘图要求见 [首轮分析指南](../docs/first_round_analysis.md)。完整轨迹留在服务器，输出位置由实际运行配置记录。
