# 实验配置与场景清单

本目录后续保存真实配置与实例清单，不保存密钥或存档。当前没有可执行配置。

已确定五个 normal 任务，每任务第一阶段 100 个场景，共 500 局基础版。建议从诊断池中每任务复用 20 个作开发子集，另留 50 个独立测试场景。

配置应确定任务规则来源、模型和生成参数、方法/代码/提示词版本、历史与记忆、纠错和网络重试规则、实例划分与抽样种子、实际可控游戏随机设置、运行顺序和输出位置。

停止规则默认采用原生终局、2,000 次环境动作宽停止线，每局 API 调用不设独立上限（max_api_calls 的配置语义为 null）。调用量作为结果记录；项目累计 50 USD 仍有效，包括先前用量与全部进程的诊断、开发、测试和消融。

具体参数见 [研究设计](../docs/llm_study_design.md)，记录与计数见 [日志规范](../docs/logging_spec.md)。先用诊断池内 25 局估算新配置开销；数量目标不根据中途成功率静默改变。所有结果关联运行时的完整配置，不能只保存一个后来被覆盖的文件名。

输出目录由配置或环境变量指定，不要求每位组员使用个人绝对路径。完整观察和轨迹留在服务器，源码和精简结果可以本地维护。
