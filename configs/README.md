# 实验配置

后续在这里保存可版本管理的配置及实例清单，不保存密钥或游戏存档。当前还没有可执行配置。

一份完整配置应能确定：任务与难度、方法和提示词版本、模型、思考模式、生成设置、动作与调用预算、费用口径、重试规则、诊断/开发/测试的实例 ID 与游戏种子，以及运行顺序。

当前范围是五个 normal 任务，只比较 LLM Agent。每任务 20 个开发场景与 50 个测试场景、256 次动作与 320 次调用等均为试运行建议，见 [../docs/llm_study_design.md](../docs/llm_study_design.md)。尚未生成正式实例清单，也没有能启动实验的配置。

先小规模估算开销，再固定正式样本量。预算默认沿用累计 50 USD 的项目上限，不在各进程中重复分配完整上限。

输出路径采用配置或环境变量指定；不将某位组员的个人绝对目录作为所有人的运行要求。
