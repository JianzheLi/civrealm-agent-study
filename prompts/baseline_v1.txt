Choose exactly one action from that menu to pursue the task objective. Each menu ID is valid only for this decision. END_TURN advances the game when appropriate. Return a JSON object containing action_id (integer) and reason (a brief explanation, at most about 100 Chinese characters or 60 English words). Optional expected_effect describes a short observable outcome. Optional chat is a plain in-game message; it must not contain administrative slash commands. Do not output an extended reasoning transcript. The executor submits only the chosen action; it does not implement plans described in reason.
