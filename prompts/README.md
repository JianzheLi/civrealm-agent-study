# 提示词与方法版本

当前已加入 `baseline.md` 和 `correction.md` 草案，用于统一基础决策和一次输出纠错；完成两个任务的单次 API 验证后再审核冻结。全组使用最新发布的同一 DeepSeek；2026-11-01 参考版本为 DeepSeek-V4.1-Flash-1017（API deepseek-flash），开始首轮时统一核对。

基础版不按成员分别修改。诊断出共同问题后再加入候选改进提示词与差异说明，不在采集前预设策略改进有效。

任务规则来自统一 TaskSpec，所有比较方法一致。方法额外使用的记忆、计划、动作描述或规则需要说明。接口协议与任务策略分开组织，便于判断改进来自输出可靠性还是行动选择。

每个正式运行记录实际使用的提示词版本；方法冻结后不根据独立测试表现静默修改同名提示词。
