# 课程报告材料

- [发展任务结果分析报告](发展任务_结果分析报告.md)：可用于课程报告的实验设置、结果、机制分析、讨论与结论，包含真实图表和数据入口。
- [失败共性分析](失败共性分析.md)：以全部100局跨海的状态变化对照成功与失败，量化关键单位损失、恢复未完成及输出停止的叠加，另列跨案例的解释性归纳。
- [固定8K的Agent改进方案](固定8K的Agent改进方案.md)：单局耗时、关键状态维护、跨回合计划、恢复前提和反馈核对，以及后续评测建议；尚未实现或启动改进实验。
- [报告写作与汇报提纲](报告写作与汇报提纲.md)：建议的叙事主线、图表讲法及六页口头汇报结构。
- report_tables.json：从正式200局逐局表汇总的资源表，包含按任务统计的耗时均值、中位数、四分位数、90%分位数和最大值，保留完整精度。
- figures/：正文图1–5、失败共性对照图与附录图S1，分别提供PNG与PDF；来源见该目录README。
- build_assets.py：根据现有结果重建表格和图，不调用模型、不改变实验配置。

本材料只涵盖development-baseline-v5-20261101的两个发展任务，保持thinking/high + 8192 tokens/请求。准备版本不混入性能统计，19个精选案例不替代完整200局的分母。原始精选材料与回放见 ../failure_diagnosis/。

在现有绘图环境中可运行 `python reports/course_report/build_assets.py` 重建图表；正文与提纲由作者结合课程总报告使用和复核。

共性统计由服务器`python scripts/analyze_common_failure_patterns.py`读取完整正式跨海轨迹生成，输出到`../failure_diagnosis/common_failure_patterns.json`及CSV，带有指标定义和事件步骤；不发起模型调用。
