# 第一轮统计、失败案例与可视化

当前先保存五任务各 100 局的精简统计、问题标签、失败案例和图表。完整轨迹与视频留在服务器，本目录记录对应的运行标识与路径。当前尚无本轮结果。

开发阶段的真实调用与机械外推见 [development_cost_check.md](development_cost_check.md)；这些运行只用于容量规划，不进入正式成功率。

| 交付 | 建议内容或名称 |
| --- | --- |
| 逐局结果 | episode_results.csv：结局、动作/回合、调用/token/耗时/单局费用与轨迹索引 |
| 逐任务统计 | task_summary.csv：覆盖、成功/失败/截断/异常、资源分布 |
| 问题标签 | failure_annotations.csv：标签定义版本、场景、证据步骤与说明 |
| 代表案例 | case_index.csv 和案例 Markdown：优先每任务 2 个失败与 1 个成功参照，以实际结局为准 |
| 汇总图 | 各任务结局分布、问题类型热力图、调用/动作/耗时分布 |
| 案例可视化 | 进展曲线或事件时间线、地图关键帧、路径图或短回放 |

以上名称和图表是交付约定，文件尚未生成。具体字段、分母、选例和回放注意事项见 [first_round_analysis.md](../docs/first_round_analysis.md)。不能用示意数据填充本轮结果，也不把状态回放冒充游戏录屏。
