# 精简交付

development/ 由真实运行的分析入口生成，包含逐局结果、全部尝试、任务汇总、待补实例、可观察标签、案例和静态图。video_index.csv 提供各局完整状态回放视频的服务器路径；视频依据真实玩家观察逐决策重建，非游戏屏幕录制。完整轨迹与视频留服务器。archive/ 在服务器及本地保留被替换配置的阶段报告，不纳入本次GitHub提交，也不能混入当前版本表现。没有策略数据时只生成明确标示未完成的覆盖表，不生成示意图。运行与数据边界见 ../docs/development_run.md。

failure_diagnosis/ 是对既有200局的进一步失败机制分析和19个本地精选案例的浏览入口。完整精选原始文件位于 ../runs/local_review/，不进入Git；本目录只保存精简证据、索引、图表与离线HTML。8K保持为本轮固定预算条件。

course_report/ 提供面向课程报告的中文正文、失败共性分析、固定8K的Agent改进设计与汇报提纲，包含5张主图、共性对照图和1张附录图的PNG/PDF，以及由逐局表生成的完整精度汇总与单局耗时分布统计。共性分析对完整100局跨海做状态追踪，改进方案尚未实现或启动新实验；正文保留固定8K设置、不同统计单位和描述性分析的结论边界。

GitHub只保存代码、配置和上述精简结果。案例Markdown中的图表和逐步摘要可直接查阅；HTML回放入口依赖本地runs/local_review/中的原始文件，克隆仓库不包含完整视频和请求账本。恢复下载方式见failure_diagnosis/README.md，需要原服务器访问权限。
