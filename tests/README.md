# 直接影响采集的检查

test_records.py 用模拟接口检查聊天与游戏动作分开计数、两次无效输出仍留完整记录、原生成功不依赖分数达标、宽停止线保留原生未知状态。模拟数据不进入实验报告。

在服务器加载现有环境后运行：

```bash
source scripts/env.sh
python -m unittest discover -s tests -v
```

原生独立SDK、128步限制移除及跨回合通知保留由 python -m civstudy.probe 检查；真实链路由每任务前5局确认。仅修改报告文字时不重复付费采集。

新增历史窗口检查用模拟环境在同一游戏回合连续执行 35 个动作，检查实际请求只保留最近 32 条历史、当前状态和合法动作仍在、输出参数为 16384，并验证新局历史清空。所有请求均为模拟，不启动游戏或付费调用。

test_openrouter.py 使用实际 OpenAI 客户端及模拟 HTTP 传输，检查专用环境变量、请求参数、JSON 纠错、报告费用与缓存、HTTP 200 内嵌错误、429 的记录且无隐式重试；不读取真实密钥，不访问外网。
